# ADR 0004 — Auth

**Decision:** Cognito Essentials
**Options rejected:** Self-rolled (security risk on health data — stated plainly); Auth0/Clerk (paid tiers)
**£/mo:** £0
**Reversal cost:** High — user migration is painful

## Amendment, Gate G1 (2026-08-21) — two user pools, not one

Added ahead of Phase 2, the same way ADR-0017 was added at G0 ahead of Phase 1: elaborating TASK 2.2.1 surfaced a constraint the one-line decision above does not survive.

**The constraint.** D-09 wants **TOTP for clinicians and email-OTP for patients**. Cognito's MFA policy is *pool-wide*: `REQUIRED` would stack a second factor on top of a patient's passwordless email OTP, and `OPTIONAL` cannot compel a clinician to enrol. One pool cannot hold both policies.

**Decision:** two user pools in `eu-west-2` — `ndn-patients` (self sign-up on, passwordless email OTP, no MFA) and `ndn-clinicians` (self sign-up disabled at the directory level, password plus `REQUIRED` TOTP). Beyond resolving the MFA policy, this makes the patient/clinician boundary structural: a patient credential cannot become a clinician credential, because the two are not in the same directory. Group membership within one pool is a softer boundary than that, and on a system holding clinical records the harder one is worth its cost.

**What it costs, stated rather than buried:** API Gateway's built-in JWT authorizer binds one issuer per authorizer and one authorizer per route, so two issuers mean a Lambda authorizer instead (TASK 2.2.2) — one more function on the authenticated request path, mitigated by API Gateway's 300-second authorizer result cache and the same arm64/128 MB/no-VPC shape as everything else. £0 either way; 509 MAU across both pools remains far inside the 10,000 free.

**Options rejected:** one pool with `cognito:groups` for roles — cheaper, lower latency, and the built-in JWT authorizer would serve. Rejected on the MFA conflict above, whose only workaround is a Pre-Authentication trigger reimplementing enforcement that Cognito already does correctly one pool boundary away.

**Not enabled:** advanced threat protection (a paid tier). The honest position is that £0 buys the directory and the MFA, not the risk engine.

**Open at the time of writing:** the Essentials free-MAU allowance and price were verified 2026-08-07 and are re-verified as TASK 2.2.1's first step, per the gate checklist's 90-day rule.
